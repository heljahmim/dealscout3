Import estate-sale listings

Paste a specific public EstateSales.NET sale URL and public listing data. DealScout does not automatically scrape EstateSales.NET.
JSON format 
{
  "title": "2017 Ford F-150 XLT",
  "category": "vehicle",
  "location": "Detroit, MI",
  "ask": 8200,
  "resale": 14500,
  "fees": 500,
  "repair": 1100,
  "risk": 7,
  "distance": 8,
  "date": "2026-10-07",
  "photos": [],
  "source": "https://www.estatesales.net/MI/Detroit/482xx/1234567"
}
