Import Estate Sales

Add public EstateSales.NET sale information to DealScout.

How this works

Paste public sale data below. DealScout will use the title, location, dates, price, resale estimate, photos and individual EstateSales.NET sale URL that you provide.

Important

DealScout does not automatically scrape EstateSales.NET pages. The browser-only version validates and stores the public sale URL you provide, while the listing information comes from the JSON or CSV data you paste.

For photos, provide actual image URLs from the sale listing. Generic stock images are intentionally not used.

Individual sale URL

Use the URL for the actual sale post, for example:

https://www.estatesales.net/MI/Detroit/48201/1234567

DealScout will place a View Estate Sale Post → button on the deal card.

Paste JSON

You can paste one listing or an array of listings.

Paste CSV

CSV headers can include: title, category, city, state, ask, resale, fees, repair, risk, days, distance, source, photos
